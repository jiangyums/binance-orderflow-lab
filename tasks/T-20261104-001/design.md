## 2. 形式化定义（本稿采用的读法）

- 置位权 `P(r) := { e ∈ A : ρ(e 的目标状态) = r }`。
- 写入面 `C(r, X) := { §6 交付物表中「状态 = X 且生产者 = r」的行的「载体」列 }`；§6 无 `X` 行时退回 `14` §6.4 的本角色允许落盘文件集（壬已裁＝不补表，该退路即终值读法）。
- **动作集合** `Act(r, X) := { e ∈ P(r) : e 的当前状态 = X } ∪ C(r, X)`。这就是交办件所说「任务推进到的当下的动作」的可判定形制。
- **用户指令的效力**：指令 `u` 不是 `A` 的元素；`u` 的作用域只在「于 `Act(本角色, 现态)` 内选择执行哪一项」与「记入台账的信息」，不改变 `A`、不改变 `ρ`、不改变 `P`。
